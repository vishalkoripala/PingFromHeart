Aura Love Heart
================

This small Python application draws an animated heart and displays a user-provided image and message.

Quick start (run from source)
-----------------------------
See the `projects/aura/README.md` for full instructions to run locally and deploy.

Live demo
---------
If you deployed with Render the demo URL will be shown on the Render service page.

Repository layout
-----------------
- `projects/aura/` — the application source (Flask app, static files, Dockerfile)
- `.github/workflows/` — CI for building and deploying the app
